## ¿Qué es esto?

`@dubalu-dev/design-system` es la librería de componentes UI interna de Dubalu.
Está construida con **React**, estilizada con **Tailwind CSS** y distribuida
como paquete privado en GitHub Packages.

## Componentes disponibles

| Categoría | Componentes |
|---|---|
| Acciones | `Button`, `Toggle`, `ToggleGroup` |
| Formularios | `TextField`, `TextAreaField`, `SelectField`, `NativeSelect`, `Checkbox`, `Switch`, `RadioGroup`, `NumberField`, `Datepicker`, `FloatingTextField` |
| Overlays | `Modal`, `AlertDialog`, `Tooltip`, `Popover`, `DropdownMenu`, `Drawer` |
| Layout | `Card`, `Tabs`, `Accordion`, `Collapsible`, `Separator`, `Progress`, `Sidebar` |
| Datos | `Table`, `DataTable`, `Pagination`, `Rating` |
| Feedback | `Badge`, `Alert`, `EmptyState`, `Skeleton`, `Spinner` |
| Tipografía | `SectionHeading`, `Label` |
| Misc | `Avatar` |
